Guia de Pesquisa: Tags Semânticas do HTML5

Aprenda a função de cada tag e como elas organizam a estrutura de uma página web.

Introdução Tags Principais Dicas

O que é HTML Semântico?

O HTML semântico utiliza tags que expressam o significado do conteúdo contido nelas. Em vez de usar apenas a tag genérica <div>, usamos tags específicas para informar a navegadores, leitores de tela e motores de busca (como o Google) o papel de cada parte da página.

Pesquisa sobre as Principais Tags

1. Tag <header>

Para que serve: Representa o cabeçalho de uma página ou de uma seção. Geralmente contém o título principal, logotipos, slogans ou campos de pesquisa.

2. Tag <nav>

Para que serve: Delimita um grupo de links de navegação principal. Facilita para os leitores de tela encontrarem rapidamente o menu do site.

3. Tag <main>

Para que serve: Envolve o conteúdo central da página. Deve haver apenas um elemento <main> por página e ele não deve conter elementos repetitivos como rodapés ou menus gerais.

4. Tag <section>

Para que serve: Agrupa conteúdos relacionados por um mesmo tema dentro do documento. Geralmente possui seu próprio título (<h2>, <h3>).

5. Tag <article>

Para que serve: Representa um bloco de conteúdo autônomo e independente (como uma notícia, post de blog ou comentário) que faz sentido por si só.

6. Tag <aside>

Para que serve: Define um conteúdo complementar ou lateral indiretamente relacionado ao conteúdo ao seu redor (ex: barras laterais, anúncios ou links extras).

7. Tag <footer>

Para que serve: Representa o rodapé do site ou de uma seção. Costuma conter informações de direitos autorais, dados de contato e links para termos de uso.

Resumo Rápido

Lembre-se das regras essenciais:

  • Apenas 1 <main> por página.
  • Evite usar <div> quando houver uma tag semântica apropriada.
  • A semântica melhora o SEO e a acessibilidade.
